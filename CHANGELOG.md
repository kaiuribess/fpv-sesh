# Changelog

## Unreleased

Initial source release of FPV Sesh for Windows.

### Editing

- Local session import, four edit styles, preview review and 4K master rendering.
- Keep/Exclude choices, exact source ranges, recovery context and saved-job resume.
- Optional music with separate source sound levels, fades and conservative beat timing.
- Vertical, square and portrait social exports with full-view or intentional crop framing.
- Pause/cancel controls, reusable completed segments and output verification records.

### Flight review

- Separate timeline bands for measured motion and optional general video observations.
- Ordinary-flight, possible-trick and uncertain filters with source/evidence details.
- Watch section playback and analysis-only Refresh understanding for saved jobs.
- Optional scene/video models and user confirmations kept distinct from predictions.

### Release preparation

- Extract-and-install launchers, local readiness checks, first-run guidance and Help.
- Keyboard navigation improvements and evidence dialogs accessible with Enter.
- User guide, troubleshooting, contribution guidelines and private-reporting policy.
- Source packages exclude footage, music, jobs, logs, downloaded runtimes and weights.

### Known limits

Trick recognition is experimental and lacks an established FPV accuracy benchmark. Upscaling does not create native camera detail. Optional inference performance and GPU encoding depend on the installed hardware and driver. HDR/log conversion, non-square-pixel normalization, gyro stabilization and synthetic slow motion are not implemented in the main ingest path. See the release notes and [user guide](docs/user-guide.md) for tested scope.
